# ПУЛЬС — Android (offline first-aid reference)

This is a **new**, dedicated repository for rebuilding and testing the PULS Android application with Android Gradle Plugin. No private user content should be published here.

Development files and build workflow live on the `qa/bootstrap` branch; `main` is only an initialization branch.

The app includes educational first-aid material. It is **not medically certified**, and emergency guidance must be clinically verified before relying on it.

Previous manually packed APK versions failed Android installation. Only trust build outputs after the CI emulator installation + launch test passes.
