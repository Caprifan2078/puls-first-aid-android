# ПУЛЬС 8.2 — улучшенная мобильная офлайн-версия

Ветка `qa/bootstrap`. Идентификатор установки: `com.puls.firstaid.rebuild.ui82`.

**Функции:** 41 двуязычная инструкция, нижняя навигация по пяти вкладкам, экстренные инструкции и телефонный вызов, категории, поиск с частичным исправлением опечаток, избранное, 3 чек-листа аптечек, недавно открытые статьи, тёмная и светлая темы, регулируемый размер текста, контрастный режим и резервная копия избранного/настроек/аптечек.

**Сборка:** GitHub Actions через Android Gradle Plugin, проверка JS, наличие и подпись APK, статическая проверка файла. Эмуляторный тест может быть недоступен по причинам работы среды; если он не запущен, не сообщайте об успехе реального запуска.

**Важно:** подпись debug в GitHub временная; новая версия устанавливается с отдельным идентификатором и не заменяет 8.1. Для следующих версий требуется постоянный секретный ключ подписи, который нельзя публиковать в репозитории.

**Медицина:** контент не сертифицирован и не прошёл независимую медицинскую экспертизу. При опасности для жизни нужно вызвать местную экстренную помощь; точность дозировок и отдельных процедур требует проверки.

**Приватность:** не выгружайте личные данные пользователя в публичный репозиторий; резервные копии содержат настройки и отметки, их не следует публиковать.
